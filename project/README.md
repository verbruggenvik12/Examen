#atletiek manager

Atletiek Manager is een webapplicatie gebouwd met Flask waarmee atleten hun prestaties eenvoudig kunnen beheren en opvolgen. Gebruikers kunnen prestaties toevoegen, bekijken, filteren en persoonlijke records raadplegen. Voor sprintdisciplines zoals 100m en 200m ondersteunt de applicatie ook windmetingen met automatische controle op geldige en ongeldige meewind volgens de atletiekregels.

#functies

- Gebruikers registreren en inloggen
- Nieuwe prestaties toevoegen
- Prestaties bekijken en filteren
- Persoonlijke records (PR's) bekijken
- Ondersteuning voor windmetingen bij sprintnummers
- Trainer/Admin omgeving voor beheer van prestaties

#benodigde instalaties

Installeer eerst de vereiste Python libraries:

- pip install flask
- pip install cs50

#applicatie opstarten

1. Open een terminal in de projectmap

2. Ga in de project map met:

- cd project

4. Start venv op met:

- .\venv\Scripts\activate

3. Start de Flask-app met:

- flask run


4. Open daarna je browser en ga naar:

http://127.0.0.1:5000

De applicatie draait nu lokaal op je computer.
